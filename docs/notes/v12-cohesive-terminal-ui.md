# Task V6 / v12: Cohesive Terminal UI Implementation Notes

## 1. Overview and Architecture

Pawmodoro is a 32-bit x86 Linux terminal productivity application developed in NASM assembly without libc, using direct `int 0x80` system calls. This task delivered a cohesive, polished, GUI-like visual design system shared across all five application screens:
1. **Menu / Dashboard**
2. **Pomodoro Timer**
3. **Habit Tracker**
4. **Journal**
5. **Settings**

Rather than five independently styled screens, the application now adheres to a single shared visual system that provides rounded border frames (`╭─╮`, `│`, `╰─╯`), explicit 7-bit ASCII fallbacks (`+-+`, `|`), consistent typography hierarchy, aligned metric cards, deterministic greetings and tips, an expanded 5-pose cat companion, and standardized status markers (`[OK]`, `[!]`, `[ERR]`, `[i]`).

---

## 2. Shared Application Shell & Six Structural Regions

Every application screen conforms to the six structural regions specified in PRD §5 and PRD_V2 §2:

1. **Brand / Header Region (Rows 1–2):**
   - Displays the Pawmodoro brand identity, a subtle sparkle accent (`✦` in UTF-8 or `*` in ASCII) styled in `SLOT_ACCENT`, and section badge.
2. **Title & Subtitle Region (Rows 2–4):**
   - Renders the primary screen title in bold `SLOT_TITLE`, contextual tagline/subtitle in `SLOT_DIM`, and deterministic greeting or cycle dots.
3. **Content Region (Middle Rows):**
   - Adaptive content area bounded by `ui_w = min(term_cols - 2, 100)` and horizontally centered with margin `ui_col0 = (term_cols - ui_w) / 2`.
4. **Panels & Cards:**
   - Framed sub-panels (`ui_panel_begin` / `ui_panel_end`), dividers (`ui_separator`), section headings (`ui_section_heading`), and aligned label-value pairs (`ui_label_value`).
5. **Status & Message Row (Fixed Location):**
   - Standardized feedback row displaying explicit text markers (`[OK]`, `[!]`, `[ERR]`, `[i]`) in addition to theme colors, ensuring color is never the sole indicator of system status.
6. **Footer & Help Bar (Row preceding bottom border):**
   - Context-sensitive keyboard shortcuts in `SLOT_DIM`, followed by the bottom border line (`ui_frame_hline_bot`) and screen wipe (`ansi_erase_eos` / `ESC[J`) to eliminate stale cells.

## 3. Theme Slots and Character Set Fallback

### 12-Slot Theme Engine Integration
Every color escape in the application is selected strictly via `ui_color` using the normative 12-slot IDs:
- `SLOT_BORDER` (0): Frame borders, panel outlines, and dividers.
- `SLOT_TITLE` (1): Main titles, section headers, and brand text.
- `SLOT_ACCENT` (2): Badges, interactive shortcuts, and sparkle accents.
- `SLOT_TEXT` (3): Primary body text and countdown digits.
- `SLOT_DIM` (4): Secondary labels, inactive items, and subtitle text.
- `SLOT_OK` (5): Success messages, completed habit squares, and enabled indicators.
- `SLOT_WARN` (6): Warnings, pause indicators, and alert prompts.
- `SLOT_ERR` (7): Error notifications and failure alerts.
- `SLOT_CAT` (8): ASCII cat artwork across all 5 poses.
- `SLOT_BAR_FULL` (9): Filled progress bar segments.
- `SLOT_BAR_EMPTY` (10): Unfilled progress bar segments.
- `SLOT_HIGHLIGHT` (11): Active selection background.

### Strict 7-bit ASCII Fallback Mode
When `setting_charset` is set to `1` (ASCII mode), the UI guarantees that:
- Every application-generated byte is strictly `< 0x80` (7-bit ASCII).
- UTF-8 glyphs map to approved single-column ASCII equivalents:
  - `─` → `-`, `│` → `|`, `╭ ╮ ╰ ╯ ├ ┤` → `+`
  - `✦` → `*`, `★` → `*`, `♥` → `v`
  - `●` → `@`, `○` → `o`
  - `▰` → `#`, `▱` → `-`
- Verified by automated test: zero bytes $\ge 0x80$ are emitted across any of the five screens when running in ASCII mode.

## 4. Adaptive Terminal Geometry & Frame Invariant

- **80×24 Dimension Safety:**
  - Frame width is `min(80 - 2, 100) = 78` columns, centered with 1-column margin (`ui_col0 = 1`).
  - All content, titles, cat artwork, progress indicators, status feedback, and key legends fit strictly within the 78-column frame without line wrapping or truncation.
- **120×40 Expansion:**
  - Frame width expands to `min(120 - 2, 100) = 100` columns, horizontally centered with 10-column margin (`ui_col0 = 10`).
  - Verified by live tmux capture: lines measure exactly 110 terminal columns (10 leading spaces + 100 frame columns).
- **One `sys_write` Per Frame Invariant:**
  - Rendering constructs the entire screen in the 8192-byte `.bss` output buffer (`out_buf`).
  - The frame is flushed with a single `sys_write` syscall (`int 0x80`) via `buf_flush`.
  - Verified by `strace -e trace=write ./build/pawmodoro`: exactly one `write` syscall is issued per screen redraw.

## 5. Screen-Specific Integrations

### A. Main Menu / Dashboard
- Displays brand header `P A W M O D O R O` and tagline.
- Deterministic greeting derived from local time hour (`05:00-11:59` morning, `12:00-17:59` afternoon, `18:00-04:59` evening).
- Compact metrics line showing `Today: N pomodoros` and `Habits: D/T done`.
- Deterministic daily cozy tip selected from `time_today % 7`. Repeated redraws on the same day show the identical tip.
- Visible `[DEMO]` badge when Demo mode is toggled on.
- Idle cat companion (Pose 0) beside header.

### B. Pomodoro Timer
- Prominent 5-row countdown presentation area with MM:SS digits.
- Phase-colored title and 4-session cycle indicator dots (`Cycle: ● ○ ○ ○` in UTF-8 or `@ o o o` in ASCII).
- 30-character segmented progress bar with `▰`/`▱` (UTF-8) or `#`/`-` (ASCII) and percentage display.
- Obvious `[PAUSED]` badge in `SLOT_WARN`.
- Companion cat pose reflecting phase: Pose 1 (Working) during focus, Pose 2 (Sleepy) during breaks, and Pose 3 (Happy) upon focus session completion.

### C. Habits Tracker
- Clear tabular header with adaptive column offsets.
- Full 31-character habit names displayed using `buf_str_clip(31)` whenever adaptive width permits (no legacy 12-char cutoff).
- 7-day history squares (`[#]` completed, `[.]` open) in oldest-to-newest order.
- Current streak and lifetime check-in metrics.
- Status feedback messages rendered via `ui_draw_status` with `[OK]`, `[!]`, `[ERR]` markers.

### D. Journal
- Scroll context indicator `[<sel+1>/<total>]` in header row.
- Formatted timestamped entries (`YYYY-MM-DD HH:MM | text`) with reverse-video highlight on active row.
- Helpful empty state ("No entries yet.") in `SLOT_DIM`.
- Full-entry viewing mode.
- Framed deletion confirmation prompt with unambiguous key hints (`[Y] Confirm delete [N/Esc] Cancel`).
- Status messages for save and delete results using explicit `[OK]` and `[ERR]` markers.

### E. Settings
- Active theme display and live 256-color palette preview.
- Aligned setting labels and values.
- Selected row highlight using `SLOT_HIGHLIGHT`.
- Framed reset-to-defaults confirmation dialog.
- Automatic rounded UTF-8 borders in UTF-8 mode and 7-bit ASCII in ASCII mode via shared `ui_frame_hline` dispatch.

## 6. Complete Procedure Inventory

The following table documents every new or modified procedure, including exact `IN`, `OUT`, and `CLOBBERS` contracts:

```
Procedure: ui_glyph_str
Purpose: Returns a pointer in ESI to the appropriate glyph string based on setting_charset (0=UTF-8, 1=ASCII).
IN: EAX = Glyph ID (GLYPH_HLINE .. GLYPH_SPARKLE)
OUT: ESI = Pointer to NUL-terminated glyph string
CLOBBERS: ESI (preserves EBX, ECX, EDX, EDI, EFLAGS)

Procedure: ui_shell_begin
Purpose: Initializes frame, gates size >= 80x24, recalculates adaptive layout, and renders rounded top border, brand, and section header.
IN: ESI = Section title string, EDI = Subtitle string (or 0)
OUT: None (appends to out_buf)
CLOBBERS: None (preserves all)

Procedure: ui_shell_end
Purpose: Renders status row, footer key help row, rounded bottom border, and clears trailing terminal lines via ansi_erase_eos.
IN: EAX = Status row, EBX = Status style, ESI = Status message (or 0), EDI = Footer help string, EDX = Bottom border row
OUT: None (appends to out_buf)
CLOBBERS: None (preserves all)

Procedure: ui_frame_emit_dashes
Purpose: Emits (ui_w - 2) horizontal border dashes ('─' in UTF-8, '-' in ASCII).
IN: None (reads ui_w and setting_charset)
OUT: None (appends to out_buf)
CLOBBERS: None (preserves all)

Procedure: ui_frame_hline_top
```
